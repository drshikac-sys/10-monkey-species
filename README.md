# Monkey Species Image Classification with Transfer Learning

This project uses transfer learning with MobileNetV2 to classify images of 10 monkey species.

## Dataset

The project uses the **10 Monkey Species** dataset from Kaggle:

https://www.kaggle.com/datasets/slothkong/10-monkey-species

The notebook downloads the dataset directly from Kaggle using `kagglehub`. You do not need to download the dataset manually or upload it to Google Drive.

The notebook combines the dataset's original training and validation folders, then creates new stratified training, validation, and test splits. The split is reproducible using a fixed random seed.

## How to Run

1. Open the public Google Colab notebook:

   https://colab.research.google.com/drive/1YHvgJnOHKtMCIZumg6odqopB8JIJGlb0?usp=sharing

2. In Google Colab, select **Runtime → Run all**.

3. If prompted, allow the notebook to access Kaggle and follow the notebook's instructions for Kaggle authentication.

4. The notebook installs or imports the required libraries, downloads the dataset, prepares the image datasets, trains the models, and evaluates the selected model.

5. Review the experiment results, training/validation plots, and prediction visualizations generated by the notebook.

## Where the Data Is Loaded

The dataset is loaded from Kaggle with `kagglehub`. The download and data-loading code is in the notebook near the beginning, in the dataset setup section.

After downloading, the notebook reads the image files from the extracted dataset directory. It uses the class folders `n0` through `n9` to identify the 10 monkey species. The notebook then creates the training, validation, and test datasets from those images.

The dataset is downloaded to the Colab runtime, so it is not stored permanently in the GitHub repository. If the Colab runtime is reset, run the notebook again to download and prepare the data.

## Model

The notebook uses **MobileNetV2** pretrained on ImageNet as the base model. A classification head is added for the 10 monkey species.

Training is performed in two stages:

1. **Feature extraction:** the pretrained base is frozen while the classification head is trained.
2. **Fine-tuning:** selected top layers of the pretrained base are unfrozen and trained with a lower learning rate.

The notebook compares multiple hyperparameter configurations and uses validation performance to select a model.

## Reproducibility

The notebook sets random seeds for data splitting and experimentation. Exact results may still vary depending on the runtime, library versions, or hardware.
